# プライズポストメーカー 設計

## 目的と安全性
Windows 10/11 x64 の店舗用ポータブルデスクトップアプリ。Tauri 2 / TypeScript / Viteを使用する。外部API・ログイン・自動投稿は利用しない。投稿前に人間が確認する。未入力の日付・商品情報を補完しない。

## 画面と処理
左に月間予定・当日入荷稼働・完売・遅延、中央に商品選択／設定／マスター／テンプレート／履歴、右に投稿プレビューを配置する。OS設定に追従するダークモードと手動切替を提供する。
商品はID、商品名、作品、キャラクター、メーカー、確認済み入荷日を持つ。複数商品を選択し、種類別の定型文と登録済み情報だけでタイトル候補・本文・タグを生成する。本文は直接編集可能。twitter-textでURL・日本語・絵文字を含むXの重み付き280文字制限を検証する。
テンプレート変数は {title} {date} {products} {note} {hashtags}。HTMLとして解釈しない。空欄日付は省略し、店舗側の確認を促す。月間は対象月で入荷予定商品を絞り込める。

## 永続化
TauriコマンドでOSのアプリデータディレクトリにJSON保存。スキーマを検証し、一時ファイルとバックアップを使って保存する。破損時はエラーを表示し、黙って初期化・上書きしない。ブラウザ開発時のみlocalStorageを使用。商品・テンプレート・作成履歴・テーマを保存する。履歴は投稿済みを意味しない。画像はセッション中のみ保持し、履歴にバイナリ・ローカルパスを保存しない。

## Xとの連携と画像
最終確認チェック後に文章コピー／Xのintent画面を外部ブラウザで開く。画像は最大4枚、JPEG/PNG/GIF/WebP、各5MBまで。GIFは1枚のみ。プレビューと元ファイル名を表示し、X側で元ファイルを手動添付する。intent経由の画像添付はできないことを明示する。

## CSV
UTF-8 BOM対応。列は name,work,character,maker,arrivalDate。引用符・カンマ・改行はCSVライブラリで処理。全行検証後に一括追加し、不正な行があれば何も変更しない。表計算式として危険な先頭文字はエクスポート時にエスケープする。名前必須・文字列長・日付実在性を検証。

## 検証と配布
各段階で型検査・既存自動テストを実行。生成・CSV・永続化データ検証・UI操作をテストする。LinuxクラウドでWindows EXEの動作確認はできない。GitHub Actions windows-latestでnpm ci、テスト、Tauriビルド後、インストーラーではない実行ファイルをZIPにしてArtifactsへ保存。WebView2 Runtimeは実行先に必要。署名なしEXEはSmartScreenの確認対象となる場合がある。

## ファイル構成
- src/main.ts: UIとイベント
- src/style.css: レイアウト・テーマ
- src/domain.ts: 商品・生成・検証・CSV・文字数
- src/storage.ts: 検証付きJSON永続化
- tests/: ドメイン・保存・UI自動テスト
- src-tauri/src/lib.rs: JSON読み書き
- src-tauri/tauri.conf.json: Windowsデスクトップ設定
- .github/workflows/windows.yml: ポータブルEXEビルド
- README.md: 使用・開発・ビルド方法
