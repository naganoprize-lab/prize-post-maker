# コンパクトUI・固定文・ツリー投稿の変更設計

main bb97465を基点に既存のExcel・商品選択・保存・履歴・X連携を維持する。

- style.css: 固定フッターとsticky追加ボタンを廃止。アプリ全体をヘッダー／可変メイン／通常フロー通知に分ける。左右パネルと商品表は独立スクロール。狭い論理画面では列数を減らし、縦方向も最小高さ0で縮められるようにする。余白を約25%削減。商品表は列幅調整と横スクロールを提供。
- excel-ui.ts: 元の行順・初期OFF・チェック対象のみの追加を維持した表表示。正式名、メーカー、日付、状態、数量を表示。投稿名編集は行内の折りたたみで保持。
- domain.ts / posts.ts: 月間は指定の店舗文を月だけ変更し、商品やタグを挿入しない。日別は指定の日付のヘッダーと商品紹介を分離。状態は手動指定された値だけを使用し、予定は未確認として表示。旧「遅延」は「入荷遅延」へ互換読込。
- thread-ui.ts / main.ts: 投稿を個別に表示・編集・確認・コピー・Xへ移動。1商品を分割せず280重み付き文字以内にまとめ、長すぎる商品は全体を警告して切り詰めない。投稿順序変更は手動。投稿ごとの確認が必要で自動投稿・自動返信はしない。
- tauri.conf.json: DPIで変わる論理画面サイズに対応する最小サイズと起動サイズ。
- tests / e2e: 固定文12か月・日付・状態・分割・過長エラー・既存の選択不変条件、縮小ビューポートとDPR1.25/1.5の矩形重なり・独立スクロールを確認。ブラウザ検証はWindows実機DPI検証の代替とは報告しない。
